# Appendix: Code Notes (for the developer)

This page is **not for the artist**. It lists the engineering work needed so the delivered art can be used, plus problems with the existing assets found while building the spec. Rows tagged **NEEDS HOOKUP** in the spec point here.

## Keeping the spec current
Run `python tools/art_manifest.py` after adding enemies, items, skills, actions, statuses, NPCs, locations, dungeons or quests. It regenerates `docs/art_spec/manifest/*` and prints the row counts.

- **`manifest/texture_fields.md`** lists every exported texture field in the scripts. When a new one appears, add it to a spec page or to the out-of-scope list in the README.
- **`manifest/texture_references.md`** lists every image in use. Files still flagged `placeholder` are outstanding.
